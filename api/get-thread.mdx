## Request

```
GET /api/thread/{threadId}
Authorization: Bearer {API_SECRET}
```

### Parameter

| Parameter | Typ | Beschreibung |
|-----------|-----|-------------|
| `threadId` | UUID | ID des Threads aus `email_threads` |
