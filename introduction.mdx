## Worum geht es?

Hannover Event ist die zentralisierte Event-Management-Plattform der BG Gastro. Sie ersetzt die bisherige manuelle Anfragenverarbeitung über verteilte E-Mail-Postfächer durch ein einheitliches System, das Anfragen automatisch erfasst, Kunden zuordnet und den gesamten Kommunikationsverlauf transparent macht.

## Tech Stack

| Komponente | Technologie | Zweck |
|------------|-------------|-------|
| Frontend | WeWeb | Web-App für Mitarbeiter |
| Backend | Supabase | Datenbank, Auth, Storage |
| E-Mail Worker | Node.js auf VPS | IMAP-Sync + SMTP-Versand |
| Reverse Proxy | Caddy | Automatisches HTTPS |
| DNS / E-Mail | IONOS | Domain + dediziertes Postfach |
